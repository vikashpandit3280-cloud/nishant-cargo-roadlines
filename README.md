# Nishant Cargo Roadlines Website

## Files
- index.html
- style.css
- script.js
- assets/

## Run
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Important
The displayed freight rates are demo/indicative rates. Replace them with actual office-approved rates before publishing.

The booking/enquiry forms open WhatsApp with the entered details. No database/admin panel is included in this static website package.
